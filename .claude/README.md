# Radiation_AX — 팀 에이전트 시스템

사규(`AI_COMPANY.md`, `AI_COMPANY_PRO.md`)의 11개 팀을 Claude Code 서브에이전트로 구현한 것.
라이브 오피스(`office-map.html`)는 이 시스템의 **시각화**이고, 실제 업무는 여기 에이전트가 한다.

## 구성
- `.claude/agents/*.md` — 팀 에이전트 11개 (팀장 코드명 = 에이전트 id).
- `.claude/commands/차수실행.md` — `/차수실행` 오케스트레이터 (파이프라인 + 승인 게이트 2곳).
- `.claude/commands/브리핑.md` — `/브리핑` 현황 5줄.
- `samples/` — 해피패스 테스트용 픽스처.

## 쓰는 법
- **차수 한 번에 실행**: `/차수실행 B8 DV1 NA VZW` → 순서대로 진행, 승인 2곳에서 정지.
- **한 팀만 호출**: "mat-chk로 이 승인원 물성 추출해줘", "spec-jdg로 이 측정 엑셀 판정해줘".
- **현황**: `/브리핑` 또는 `/브리핑 왜 늦어져?`.

## 규칙 (모든 에이전트 공통)
- 대표 승인 2곳(측정 진입 전 / 차수 마감 전)에서 반드시 멈춘다.
- 입력 파일 없으면 `[상태: 연동대기]` + 없는 파일 명시하고 멈춘다.
- 원본(.prt·시뮬·raw)은 복제본에만, 메일은 초안까지, 미완료를 완료로 보고 금지.
- 산출물 저장: `D:\AX\AI Company`.

## 향후 (범위 밖)
ADS/CST/엑셀 **실제 구동**은 team-tools MCP(`D:\AX\Multiple agent MCP`)로 붙인다.
지금 에이전트는 입력 파일을 읽어 구조화·검증·산출물 생성까지. 실 계측/시뮬 실행은 MCP 연결 후.
NX·3D 챔버는 AI 미구동 도구라 사람이 파일을 전달해야 진행된다.
